# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it and what it affects.

You can expect an acknowledgement within a few days. This is a demonstration project maintained by one person, so fixes are made on a best-effort basis.

## Supported versions

Only the latest commit on `main` is supported.
